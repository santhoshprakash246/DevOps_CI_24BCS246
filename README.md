# Blood_Bank_Management_System

A simple Java application for tracking blood units by blood group. The service supports adding stock, checking available units, and issuing units while preventing stock from going below zero. Stock is stored in memory and resets when the application process ends.

## Technologies

- Java 17
- Apache Maven
- JUnit 5

## Run the tests

From the project root, run:

```bash
mvn test
```

The application logic is in `src/main/java/com/bloodbank/BloodBankService.java`, with JUnit tests in `src/test/java/com/bloodbank/BloodBankServiceTest.java`.
